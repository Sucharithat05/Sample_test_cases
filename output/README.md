# UI Explorer locator outputs

JSON files in this folder are generated by the **UI Explorer Agent** from the Markdown test cases under `test-cases/`.

| File pattern | Description |
|--------------|-------------|
| `ui_explorer_<TEST_CASE_ID>.json` | Per-step locators discovered while running that case |

Source agent: local `ui-explorer-agent` project  
Input repo: https://github.com/Sucharithat05/Sample_test_cases

Do not edit these files by hand unless you are intentionally updating expected locator snapshots.
